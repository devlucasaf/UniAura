O que você vai aprender

Do básico ao avançado, com foco em desenvolvimento de software, banco de dados e metodologias ágeis — sempre com projetos práticos a cada semestre.

Programação Web e Mobile

HTML, CSS, JavaScript, C#, frameworks modernos e desenvolvimento de aplicativos.

Banco de Dados

Modelagem, SQL, NoSQL e integração de dados com as aplicações que você constrói.

Metodologias Ágeis

Scrum, Kanban e práticas de desenvolvimento colaborativo em equipe.

Infraestrutura e Nuvem

Redes, containers, computação em nuvem e publicação de aplicações em produção.

Qualidade de Software

Testes automatizados, revisão de código e garantia de qualidade do que é entregue.

Análise de Sistemas

Levantamento de requisitos, modelagem de processos e projeto de soluções.
