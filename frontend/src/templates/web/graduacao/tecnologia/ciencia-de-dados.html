Ciência de Dados

Transforme dados em decisão. Estatística, programação e aprendizado de máquina aplicados a problemas reais de negócio, saúde, indústria e governo — do primeiro SELECT ao modelo em produção.

desempenho_por_curso.sql
SELECT c.nome AS curso, COUNT(DISTINCT m.aluno_id) AS alunos, ROUND(AVG(n.valor), 2) AS media FROM matricula m JOIN turma t ON t.id = m.turma_id JOIN curso c ON c.id = t.curso_id JOIN nota n ON n.aluno_id = m.aluno_id WHERE m.status = 'ATIVA' GROUP BY c.nome ORDER BY media DESC;
